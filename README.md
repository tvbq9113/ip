## 一、先搞清楚：高防 IP 到底防什么

高防 IP 的本质，是把一个带 DDoS 清洗能力的 IP 挂到你业务前面。攻击流量先打到这个高防 IP，经过清洗中心的过滤，正常流量再回源到你真正的服务器。换句话说，你的源站 IP 被藏起来了，攻击者打的是“替身”。

它能防的主要是这几类：

- **流量型 DDoS**：SYN Flood、UDP Flood、ICMP Flood 这类靠大流量把带宽打满的攻击
- **协议型攻击**：畸形报文、分片攻击这类靠协议漏洞消耗资源的攻击
- **资源耗尽型**：连接数耗尽、HTTP 慢速攻击这类把服务器连接池打光的攻击
- **CC 攻击**：模拟真实请求把应用层拖垮的攻击，通常按 QPS 衡量

需要说明的是，高防 IP 不是万能的。如果你的业务本身有逻辑漏洞（比如一个接口被刷就能拖垮数据库），高防 IP 顶多帮你挡住流量层，应用层的优化还得你自己做。

## 二、租用前必须看懂的几个参数

很多人下单时只盯着“多少 G 防御”这一个数字，其实高防 IP 的计费维度不止这一项。以恒创科技的高防 IP 为例，订单页上影响价格和体验的参数主要有这几个：

**弹性防护峰值**：这是“按次付费”的额外防护。当攻击流量超过保底峰值但没超过弹性峰值时，系统会按当日攻击峰值对应档位收费。恒创科技的弹性计费规则是按 G 收费，30G 保底的香港高防 IP 可弹性防御到 90G，每 G 约 5 元。如果你平时攻击不大但偶尔被放大攻击，弹性防护比直接买高保底划算。

**业务带宽**：这是高防 IP 回源到你服务器的带宽。带宽不够会导致正常访问丢包，所以要根据无攻击时的峰值流量来选。恒创香港高防 IP 标配双向 CN2 GIA 精品带宽。

## 三、高防 IP 和高防服务器，别选错

这两个产品经常被混在一起说，但适用场景差别挺大。

**高防服务器**是“服务器本身带防御”，你租的是一台物理机或云主机，机房出口架设了硬件防火墙。适合从零开始部署、对硬件性能有要求、希望服务器和防御打包管理的场景。缺点是换防御往往意味着换机器或换机房，灵活性差。

**高防 IP** 是“独立于服务器的防御入口”，你原来的服务器不用动，只要把域名解析或业务指向改到高防 IP 上就行。适合已经有服务器、不想迁移数据、或者源站在别的厂商但想加一层防御的场景。优势是接入快（恒创官方说最快 3 分钟），弹性扩容秒级生效，服务不中断。

简单判断：

- 业务还没上线，或者本来就打算换机器 → 直接看高防服务器
- 服务器已经在跑、数据不想动、只是被打了想加防御 → 高防 IP 更合适
- 攻击波动大、平时小打偶尔大打 → 高防 IP 的弹性防护比固定高保底省钱

## 五、接入流程：从下单到生效要做什么

高防 IP 的接入比高防服务器简单很多，核心就两步：把业务流量引到高防 IP，再让高防 IP 把干净流量回源到你服务器。恒创提供两种接入方式：

**DNS 解析接入**：把你的域名 A 记录或 CNAME 改指向高防 IP，访问流量自动经过清洗再回源。适合网站类业务，配置最简单。

**IP 直接指向接入**：客户端或 App 直接访问高防 IP，高防 IP 转发到源站。适合游戏、App 后端这类通过 IP 直连的非网站业务。

接入后有几个细节要注意：

1. **源站 IP 一定要保密**。如果源站 IP 之前被攻击暴露过，建议接入高防 IP 后更换源站 IP，否则攻击者可能绕过高防直接打源站。
2. **协议和端口要配对**。接入配置的协议（TCP/UDP/HTTP/HTTPS）和端口必须和实际业务一致，配错会导致防护失效或业务中断。
3. **防护数据可在控制台查看**。恒创控制台有防护概览、安全监控、攻击事件和日志功能，可以按时间段查看统计报表。
4. **弹性防护按需附加**。如果买的时候没买弹性防护，后期可以补加；如果弹性次数用完，需要重新附加才能继续用。

## 六、几个常被问到的问题

**Q：30G 够不够用？**
看你的攻击历史。如果平时被打不超过 20G，30G 保底够用，偶尔被放大攻击时靠弹性防护兜底就行。如果你做过游戏、支付、金融这类高频被攻击的业务，建议直接上 60G 保底起步。

**Q：弹性防护怎么收费？**
恒创的规则是：附加弹性防护费用 = 弹性防护峰值的单日单次价格 × 高防 IP 实例剩余有效天数 × 弹性防护次数。30G 保底可弹性防御到 90G，每 G 约 5 元。也就是说，平时不触发不收钱，只有真被打超过保底峰值的那天才按档位计费。

**Q：高防 IP 会被打穿吗？**
会。如果攻击流量超过弹性防护峰值，高防 IP 会进入黑洞（自动封禁 IP），业务会中断。恒创支持联系客服手动升级到更高防御解封，香港高防云服务器支持弹性升级且服务不中断，但高防 IP 本身被打穿后需要人工介入。

**Q：源站在别的厂商能用恒创高防 IP 吗？**
能。高防 IP 是独立服务，不要求源站也在恒创。只要你能改 DNS 解析或把业务指向高防 IP，源站在阿里云、腾讯云、自建机房都可以接。

**Q：支持哪些付款方式？**
支付宝、PayPal、微信支付、银行在线转账、银行线下转账。
